<h3>Основной функционал</h3>

1. *companies_search* - для поиска ***id*** данного списка работодателей из HeadHunter.
2. *vacancies_search* - для поиска ***open vacancies***  из предоставленного списка работодателей, идентификатора от HeadHunter.
3. *db_manager* - для создания базы данных и таблиц PostgreSQL. 
Заполнение таблиц информацией, предоставляемой классами **HeadHunterCompanies** и **HeadHunterVacancies**.
Предоставление методов, используемых в основной функции для работы с базой данных.
4. *logger.py* - настройка регистратора.

<h3>Как работает программа</h3>

1. Приложение запускается с запроса списка компаний, которые пользователь хотел бы найти. 
**Если оставить поле пустым** - будет выбран список компаний по умолчанию. 
2. Пользователь подключается к базе данных и создает таблицы для заполнения.
3. Поиск инициализируется. Проанализированная информация заполняется в таблицах
4. Пользователь выбирает один из вариантов в меню выбора.
